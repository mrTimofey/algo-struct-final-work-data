# Данные итогового проекта

Набор районов и два скрипта для итогового проекта курса «Алгоритмы и структуры данных». Само задание и приложение к нему выдаются отдельно, здесь лежит только то, на чём работа запускается.

| Каталог | Что внутри |
| :---- | :---- |
| [data/](data/README.md) | Шестнадцать районов из снимка OpenStreetMap от 15 ноября 2026 года, по файлу `.osm.gz` на район, и каталог с числами каждого района |
| [tools/](tools/README.md) | `extract_district.py` готовит рабочие таблицы района, `generate_orders.py` создаёт поток заказов |

Скриптам нужен Python 3 и больше ничего. Сторонняя библиотека `osmnx` понадобится, только если вы выгружаете свой район по названию или по прямоугольнику.

## С чего начать

Найдите свой район в [каталоге](data/README.md) по номеру в списке группы. Затем из корня репозитория выполните две команды, подставив имя своего файла:

```
python3 tools/extract_district.py --osm-xml data/06-kazan-center.osm.gz --out work/district
python3 tools/generate_orders.py --district work/district --seed 4242 --count 200 --variant base --out work/orders --with-truth
```

Первая команда печатает число вершин, рёбер, зданий с адресом и улиц. Сверьте их со строкой своего района в каталоге: файл и скрипт закреплены, поэтому числа должны совпасть до единицы. Если не совпали, проверьте файлы по контрольным суммам:

```
cd data && shasum -a 256 -c SHA256SUMS
```

Вторая команда пишет в `work/orders` заказы, сценарий доставки и разметку с правильными ответами. Значение `--seed` вы выбираете сами и фиксируете в отчёте, сценарии `--variant` описаны в приложении к заданию. Ключи обоих скриптов описаны в [tools/README.md](tools/README.md).
